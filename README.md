## Module 1 — Foundations of Problem Solving
### Chapter 1 — Time Complexity
- Big-O / Big-Θ / Big-Ω notation  
- Common complexity classes and examples (O(1), O(log n), O(n), O(n log n), O(n²), etc.)  
- Master theorem for divide & conquer  
- Amortized analysis (e.g., dynamic arrays, union-find)

### Chapter 2 — Space Complexity
- Auxiliary vs total space  
- Recursion stack usage and tail recursion  
- Time–space tradeoffs and common optimizations

### Chapter 3 — Mathematical Fundamentals
- GCD/LCM (Euclidean algorithm)  
- Prime testing and sieve (Sieve of Eratosthenes)  
- Modular arithmetic and modular inverse (Fermat / extended Euclid)  
- Combinatorics basics (nCr fast computation)  

### Chapter 4 — Recursion & Divide & Conquer
- Recursion patterns and recursion trees  
- Converting recursion → DP  
- Typical problems: mergesort pattern, quickselect

## Module 2 — Data Structures & Their Applications
### Chapter 5 — Arrays & Strings
- Two pointers, prefix/suffix, sliding window  
- String matching (KMP, Z, Rabin-Karp)  
- Common array patterns (subarray sums, sorting + two-sum variants)

### Chapter 6 — Linked Lists
- Single / double / circular lists  
- Fast/slow pointer patterns, cycle detection, reverse, merge

### Chapter 7 — Stacks & Queues
- Monotonic stack, stack for expression evaluation  
- Deque applications, circular queue, priority queue basics

### Chapter 8 — Hashing
- Hash maps/sets (collision handling, complexity)  
- Rolling hash for strings, custom hash for pair keys

### Chapter 9 — Trees
- Binary tree traversals, BST operations  
- Tries, segmenting string problems with tries  
- LCA, tree DP basics

### Chapter 10 — Heaps & Priority Queues
- Heap operations, building heaps, k-largest problems

### Chapter 11 — Graphs
- Representations (adj list / matrix)  
- BFS, DFS, connected components, bipartite checks

### Chapter 12 — Shortest Paths & MST
- Dijkstra, Bellman-Ford, Floyd-Warshall  
- Kruskal, Prim (MST)

## Module 3 — Advanced Algorithms & Techniques
### Chapter 13 — Two Pointers & Sliding Window
- Fixed / variable windows, sliding window templates

### Chapter 14 — Sorting & Searching
- Binary search (including "binary search on answer")  
- MergeSort, QuickSort, stable vs unstable sorts

### Chapter 15 — Greedy Algorithms
- Interval scheduling, activity selection, canonical greedy proofs

### Chapter 16 — Dynamic Programming
- Memoization vs tabulation  
- 1D/2D DP, knapsack, LIS, DP on trees, bitmask DP, DP on graphs

### Chapter 17 — Bit Manipulation
- XOR properties, bit masks, subset enumeration tricks

### Chapter 18 — Segment Trees & Fenwick Trees
- Range queries, point updates, lazy propagation

### Chapter 19 — Backtracking
- Permutations, combinations, classic N-Queens, sudoku

## Module 4 — System Design (LLD & HLD)
### Low-Level Design (LLD)
- OOP design, SOLID principles, common patterns (Factory, Singleton, Strategy, Observer)  
- LLD practice problems (design a parking lot, rate limiter, chat message model)

### High-Level Design (HLD)
- Scalability fundamentals: horizontal vs vertical scaling, caching, CDNs, load balancing  
- Database design: indexing, replication, sharding, normalization vs denormalization  
- CAP theorem and consistency models  
- API design: REST/GraphQL, authentication flows, rate limiting  
- Messaging: queues, pub/sub, event sourcing (Kafka/ SQS / RabbitMQ)  
- Case studies: YouTube (streaming), Uber (geolocation & matching), WhatsApp (messaging at scale)
